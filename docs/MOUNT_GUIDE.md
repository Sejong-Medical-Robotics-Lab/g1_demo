# 머리 카메라 마운트 — 조립·출력 안내

`g1_head_cam_mount.scad` / `g1_head_cam_mount.stl`

D435i 를 G1 정수리에 다는 마운트. 나사 구멍이 없는 곡면이라 **벨크로
스트랩으로 감싸 고정**하는 구조다.

---

## 치수 출처와 신뢰도

정수리 곡률은 실물을 잰 것이 아니라 **Unitree 공식 URDF**
(`unitreerobotics/unitree_ros`, `head_link.STL`)를 직접 파싱해 얻었다.

```
정수리 최고점 45mm 이내 1957점을 최소자승 구 피팅:
  중심 오프셋 (1.6, 0.0)mm — 거의 정중앙
  반지름 68.9mm  (잔차 평균 1.0mm, 최대 2.9mm)
→ 처음 눈대중으로 75mm 라 했다가, 실제 메시와 대조해 68.9mm 로 정정.
  안장 안쪽면-실물 간격이 평균 0.7~1.0mm 수준으로 확인됨.
```

**모델과 실물은 도장·성형 공차로 몇 mm 차이 날 수 있다.** 출력 전에
아래 "실물 확인" 순서를 반드시 거친다.

---

## LiDAR — 제약 아님으로 확정 (2026-08-24)

처음엔 "MID360 이 정수리 위쪽을 본다"고 가정하고 안장을 33mm 로
좁혔었다. **실물 확인 결과 이 가정이 틀렸다:**

- LiDAR 는 머리 돔 **아래 빈 공간의 천장에 거꾸로 매달려** 그 빈
  공간을 통해 옆을 본다. 정수리 바깥 곡면과는 무관하다.
- 커뮤니티(deepglint/FAST_LIO_LOCALIZATION_HUMANOID)도 "G1 의
  MID360 은 뒤집혀 있다(roll=180)"를 공식 확인 — 같은 구조다.
- 카메라(D435)는 정면 눈 쪽 내장 — 역시 정수리와 무관.

그래서 안장을 **반지름 45mm 로 확장**했다(스트랩이 잡을 자리 확보).
55mm 까지 시도했으나 실측 대비 가장자리가 최대 8mm 뜸(실제 머리가
완전한 구가 아니라서) — 45mm 가 밀착(최대 4.4mm)과 넓이의 적정선.
출력해 얹은 뒤:

```bash
lidar
ros2 launch livox_ros_driver2 rviz_MID360s_launch.py
```

RViz 에서 마운트가 놓인 방향에 **빈 부분(그림자)이 생기는지** 확인한다.
생기면 `saddle_fit_radius` 를 줄이거나 마운트 위치를 살짝 옮긴다.

---

## 실물 확인 (출력 전, 5분)

1. `saddle_fit_radius`(45mm)를 지름으로 환산한 90mm 원을 종이에 그려 오린다
2. 로봇 정수리에 대보고 **딱 맞는지, LiDAR 를 가리지 않는지** 확인
3. 안 맞으면 파라미터를 조정하고 다시 렌더

```bash
sudo apt install openscad          # 없으면
openscad g1_head_cam_mount.scad    # 창이 열리고 3D 로 확인 가능
```

---

## 파라미터 조정

`.scad` 파일 상단 값을 바꾸면 된다. 자주 손댈 것:

| 변수 | 기본값 | 의미 |
|---|---|---|
| `saddle_fit_radius` | 45mm | 안장이 덮는 범위. 실물 대보고 조정 |
| `riser_h` | 26mm | 카메라를 얼마나 들어올릴지 |
| `CAM_TILT_DEG` | 12° | 양수=아래로 기움, 음수=위로 기움 |
| `strap_slot_w` | 17mm | 쓰는 벨크로 폭+2mm |

바꾼 뒤 다시 렌더:
```bash
openscad -o mount.stl g1_head_cam_mount.scad
```

### 각도는 출력 후 실측으로 정한다

12°는 초기값일 뿐이다. 정수리는 눈높이보다 훨씬 높아서, 기존 가슴
카메라(45° 아래)와는 다른 각도가 필요하다. **출력 후 `--dry-run` 으로
띄워보고, 사람이 2~3m 거리에 섰을 때 상반신이 화면 중앙에 오도록
`CAM_TILT_DEG` 를 조정해 다시 출력한다.**

```bash
python3 ~/g1_real/g1_pose_action.py --dry-run
```

## 출력

- **재질**: PLA
- **서포트**: 필요 (카메라판이 기울어져 있다)
- **놓는 방향**: 안장의 오목한 면(머리 닿는 쪽)을 베드 쪽으로. 기둥과
  카메라판이 위로 향하게 — 서포트가 최소화된다
- **인필**: 20% 이상 (카메라 96g 을 지지해야 한다)
- **예상 무게**: 약 18g (20% 인필 기준)

---

## 조립

1. 15mm 폭 벨크로(또는 케이블 타이) 두 개를 준비한다
2. 앞뒤 슬롯에 하나, 좌우 슬롯에 하나를 통과시켜 **십자로 교차**하게 두른다
3. 머리에 얹고 벨크로를 당겨 고정한다
4. D435i 를 카메라판에 1/4-20 나사로 고정한다 (M3 두 개는 회전 방지용,
   필요 없으면 생략 가능)
5. USB 케이블을 케이블 릴리프 홈으로 빼서 목 쪽으로 늘어뜨린다

---

## 이 설계에서 실제로 부딪힌 문제 — 참고용

만들면서 세 가지가 틀렸었다. **셋 다 렌더는 성공했는데 형상이 잘못돼
있었다** — OpenSCAD 는 이런 실수를 경고해주지 않는다.

**① 절단 도형이 대상을 못 덮음**
안장을 반지름으로 자르는 원기둥의 높이를 너무 짧게(12mm) 잡아서,
안장이 실제로 있는 z 범위(정수리 부근, 약 -79~-39)를 전혀 안 덮었다.
결과: 교집합이 통째로 빈 도형. 렌더는 "성공"했지만 `vertices=0`.

**② 두 부품이 겉보기엔 붙어 있는데 실제로는 안 붙음**
안장과 기둥을 서로 다른 기준점으로 계산해서, 렌더 이미지로는 맞닿아
보였지만 실제로는 한 점에서 스치기만 했다. `mesh.split()` 으로 조각
수를 세어보고서야 2개로 분리된다는 걸 알았다.

**③ 방향이 반대로 계산됨**
기둥이 "머리 반대편으로 자라야" 하는데, 처음엔 머리 쪽(안장의 안쪽
면)에서 시작해 안쪽으로 자라도록 계산되어 있었다.

**교훈**: 3D 형상은 **렌더 성공 여부나 눈으로 보이는 이미지로는
검증이 안 된다.** 부피·조각 수·특정 지점이 재질 안인지 밖인지를
직접 계산해서 확인해야 한다(이 파일은 `trimesh` 로 그렇게 검증했다).
